CO-1: Git, Version Control & Semantic HTML5 Implementation
  • Git & Version Control: Initialized local git repo, created .gitignore, structured workflow with commit history and remote repository readiness for GitHub.
  • Semantic HTML5 Structure: Proper usage of <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, <details>, and <summary>.
  • SEO & Metadata: Configured meta charset, viewport, description, author, and keywords.
  • Form Enhancements: Applied required, placeholder, pattern, autofocus, and proper input types in the contact section.
CO-2: CSS3 Selectors, Box Model, Flexbox & CSS Grid Layout
  • Types of CSS: External CSS in style.css, Internal CSS in <style>, and Inline CSS sample.
  • Selectors Used: Universal (*), Element (body, h1, p), Class (.btn, .project-card), ID (#projects, #contact), Group (h1, h2, h3), Descendant (.navbar ul li a), and Pseudo-classes (:hover, :focus, :active, :nth-child).
  • CSS Box Model: Explicit calculation with margins, borders, padding, and box-sizing: border-box.
  • Layout Systems: CSS Grid (display: grid, grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))) for Project Gallery; Flexbox (display: flex) for Navigation, Hero, and Action buttons.
  • Transitions & Transforms: Hover lifts (transform: translateY(-4px)) and smooth transitions.
CO-2: Core JavaScript, Fetch API, DOM & LocalStorage
  • Async/Await & Fetch API: Asynchronously pulls real GitHub user data & repository cards from https://api.github.com/users/AbhijeetArjeet/repos.
  • DOM Manipulation: Dynamically creates, filters, and mounts cards using document.getElementById, createElement, and event listeners.
  • Form Validation: Validates inputs on submission, shows inline status/error messages.
  • Local Storage (CO-2 requirement): Persists contact form feedback and friend portfolio URLs so data stays after page reload.
